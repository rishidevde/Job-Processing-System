# Samruddhi HMS — Unified Hospital Management & Clinical Suite

A high-performance, responsive Hospital Management System (HMS) built to connect every clinical, diagnostic, and administrative touchpoint into a single unified patient journey.

### Live Demo & Links
- **Live Deployment**: [https://kenpathlabs-hms.vercel.app/](https://kenpathlabs-hms.vercel.app/)
- **GitHub Repository**: [https://github.com/rishidevde/Job-Processing-System](https://github.com/rishidevde/Job-Processing-System)

---

### Key Highlights & Features
- **Zero-Cross-Contamination Authentication**: Staff select their profession (Doctor, Nurse, Pharmacist, Lab Tech, Receptionist, Cashier, Admin), verify credentials via registered mobile and access password, and land strictly on their isolated workstation workflows.
- **23 Connected Functional Workbenches**: Spans OPD triage, clinical documentation, prescription orders, phlebotomy & specimen accessioning, pharmacy inventory & dispense, multi-payer split billing, and automated document assembly.
- **Real-Time Reactive State**: Synchronized patient journey across all workstations with zero page reloads, optimistic UI, and instant cross-department handoffs.
- **Live System Clock**: Dynamic real-time ticking clock with seconds, synchronized for audit trails and time-stamped clinical notes.
- **Strict Viewport Architecture**: 100vh panel-scrolling layout optimized for clinical workstations and mobile data.

### Setup & Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rishidevde/Job-Processing-System.git
   cd Job-Processing-System
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Production Build**:
   ```bash
   npm run build
   npm run preview
   ```
